# Питание

Веб-приложение для прохождения программы метаболического похудения.
Работает в браузере, ставится на телефон с домашнего экрана, офлайн.
Без регистрации и сервера: всё хранится в браузере устройства.

## Важно: материалов курса здесь нет

Меню, рецепты, лист продуктов и описания упражнений — материалы платного
курса, поэтому **в репозиторий они не выкладываются**. В коде лежит только
движок: расчёты, интерфейс, дневник.

При первом запуске приложение просит подключить файл с материалами
(`content-pack.json`). Файл читается прямо в браузере, никуда не
отправляется и сохраняется только на устройстве пользователя.

Структура файла:

```
{
  "P":      { идентификатор: { n, c, pg, k, cb, ku? } },   лист продуктов
  "CATS":   [ категории ],
  "MEALS":  [ приёмы пищи дня со слотами и способами ],
  "RECIPE": { рецепт блюда },
  "WR":     [ водный режим ],
  "EX":     [ упражнения ],
  "ALLERG": [ аллергены ], "AIDS": { аллерген: [продукты] },
  "KASHI": [], "BERRIES": [], "OILS": [], "FISH": []
}
```

## Что приложение считает само

- **Расписание дня** — от времени завтрака и перерыва, с правилом «ужин
  до 19:00»; поздний перекус — от времени сна.
- **Норма воды** — 30 мл на кг веса, не ниже 2 л для женщин (EFSA).
  В материалах курса формулы нормы нет, это клиническое правило.
- **Калорийность приёма** — по выбранным продуктам и граммовкам, в двух
  источниках: по методичке и по USDA (показывается там, где расходятся).
- **День программы и ступень** — от даты старта: Детокс 7 дней,
  Экспресс 14, Марафон 30, дальше Баланс.
- **Путь к цели и ИМТ** — от роста, веса и цели.

Кнопка «?» в правом верхнем углу показывает формулу под каждой цифрой.

## Иллюстрации упражнений

`assets/exercises/` — оригинальные иллюстрации, сделанные для этого проекта.

## Разработка

Статические файлы, сборка не нужна:

```
cd pitanie
python3 -m http.server 8000
```

Публикуется на GitHub Pages воркфлоу `.github/workflows/deploy-nutrition-app.yml`
при пуше в `main`, адрес — `/pitanie/`.
