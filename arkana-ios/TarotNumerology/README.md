# Аркана — Таро и Нумерология (iOS MVP)

Нативное SwiftUI-приложение. Контекст проекта, принятые решения и статус —
в [`../CLAUDE.md`](../CLAUDE.md) и [`../PRODUCT_MISSION.md`](../PRODUCT_MISSION.md).

## Требования

- Xcode 15+ (полная версия, не только Command Line Tools) — для сборки и
  запуска в симуляторе, а также для компиляции SwiftData `@Model`-макросов.
- [XcodeGen](https://github.com/yonaskolb/XcodeGen) — генерирует `.xcodeproj`
  из `project.yml`, чтобы не хранить хрупкий бинарный проектный файл в репозитории.

## Как собрать и запустить

```bash
brew install xcodegen   # если ещё не установлен
cd TarotNumerology
xcodegen generate
open TarotNumerology.xcodeproj
```

Дальше в Xcode: выбери симулятор iPhone, `Cmd+R`.

## Что стоит проверить при первом запуске

- Онбординг: ввод имени (+опционально дата рождения), переход на главный экран.
- Главный экран: приветствие по имени, переход в Таро/Нумерологию/Историю.
- Таро → «На вопрос или желание»: ввод вопроса, 3 карты рубашкой вверх, тап
  переворачивает карту (3D-анимация), случайная прямая/перевёрнутая ориентация,
  вкладки Ситуация/Совет/Итог, сохранение в историю.
- Таро → «Карта дня»: одна карта, тот же флип.
- Нумерология → Личный расчёт: ввод имени/даты, три карточки чисел (судьбы,
  души, характера), толкование выбранного числа, сохранение.
- Нумерология → Совместимость: два человека, число судьбы каждого, толкование пары.
- Нумерология → Прогноз дня: работает только если дата рождения указана
  (при онбординге или в личном расчёте).
- История: показывает все сохранённые расклады/расчёты, сортировка по дате.

## Известные ограничения MVP (см. CLAUDE.md за подробностями)

- Все визуальные ассеты (hero-изображение, иллюстрации карт, звук переворота) —
  программные заглушки, а не финальная графика заказчика.
- Данные нумерологии (таблица букв, банк прогнозов дня, таблица совместимости)
  — черновики, требуют проверки практикующим нумерологом.
- Код написан и типопроверен без доступа к полному Xcode (в песочнице
  разработки был только Command Line Tools) — типы и логика расчётов
  проверены отдельно, но **полная сборка и визуальная проверка в симуляторе
  ещё не выполнялись** и должны быть сделаны здесь при первом запуске.
