# ТЗ: мобильное приложение «Таро и Нумерология»

## 1. Общее описание
Мобильное приложение с двумя разделами: Таро и Нумерология. Единая дизайн-система, тёмная тема, разные акцентные палитры для разделов. Язык интерфейса — только русский. Аудитория — обычные пользователи без специальных знаний в Таро/нумерологии, тексты простые, без эзотерического жаргона.

## 2. Структура приложения

### 2.1 Главный экран
- Верхний блок — изображение на весь экран (без рамки), плавно растворяется градиентом в тёмный фон книзу; изображение предоставляет заказчик
- Ниже, на чистом тёмном фоне — название приложения
- Персональное приветствие по имени, отдельной строкой, плюс вопрос-приглашение (текст в проработке)
- Два раздела для перехода: Таро (первый), Нумерология (второй)

### 2.2 Раздел «Таро»
- Экран выбора типа запроса: расклад на желание/вопрос ИЛИ расклад на день
- Экран расклада: карты рубашкой вверх, по тапу переворачиваются с анимацией; при выпадении карта случайно определяется как прямая или перевёрнутая (реверс)
- MVP-расклад: 3 карты — ситуация / совет / итог (либо карта дня для короткого сценария)
- Толкования — классические значения по системе Уэйта, для прямого и перевёрнутого положения (полный список — см. tarot_numerologiya_kontent_v2.md)
- **Архитектурное требование:** структура данных карт должна изначально поддерживать второй слой текстов — авторские персонализированные толкования с учётом сочетаний карт (этап 2), без переделки схемы
- Обращение к пользователю по имени в тексте толкования
- Возможность сохранить расклад в историю

### 2.3 Раздел «Нумерология»
- Внутренние вкладки: Личный расчёт / Совместимость / Прогноз дня
- Личный расчёт по дате/времени рождения (событие — опционально): выводится набором ключевых чисел карточками (число судьбы, число души, число характера и т.д. — полный набор), ниже разворачивается толкование по выбранному числу
- Проверка совместимости (ввод данных двух людей)
- Прогноз на день
- Обращение по имени в результатах
- Возможность сохранить расчёт в историю

### 2.4 История
- Список всех прошлых раскладов/расчётов с датой, вопросом и результатом
- Доступна без регистрации (хранится локально на устройстве)

## 3. Регистрация и хранение данных
- Регистрация опциональна: пользователь может пользоваться приложением без аккаунта
- Без аккаунта — история хранится локально на телефоне
- С аккаунтом (добавляется позже) — синхронизация истории через облако
- **Решение по MVP:** начинаем без регистрации и без бэкенда, только локальное хранение. Регистрация и облачная синхронизация — этап 2

## 4. Push-уведомления
- Не входят в MVP
- Техническую возможность добавить позже (например, напоминание сделать расклад дня) заложить, но не разрабатывать в первой версии

## 5. Дизайн
- Тёмная тема на весь интерфейс, чёрный фон
- Единая система: шрифты, иконки, анимации, стиль карточек — общие для обоих разделов
- Раздел Таро — палитра глубокого зелёного (природно-эзотерический стиль)
- Раздел Нумерология — сине-фиолетовая палитра (космически-мистический стиль)
- Звук и анимация при открытии карты Таро
- Мокапы главного экрана, экрана Таро и экрана Нумерологии готовы (см. приложенные изображения home_screen.png, tarot_screen.png, numerology_screen.png)
- Вординг текстов интерфейса требует доработки (в процессе)

## 6. Монетизация
- Не входит в MVP
- Архитектуру заложить так, чтобы подписку/покупки можно было добавить на этапе 2 без переделки

## 7. Язык и аудитория
- Только русский язык интерфейса
- Целевая аудитория — новички, широкая, без экспертных знаний в Таро и нумерологии

## 8. Этапы разработки
**Этап 1 (MVP):**
- Оба раздела с классическими толкованиями/расчётами
- Работа без регистрации, локальная история
- Дизайн-система и мокапы всех ключевых экранов готовы

**Этап 2:**
- Регистрация и облачная синхронизация истории
- Авторские персонализированные тексты для Таро (комбинации карт)
- Монетизация (подписка/покупки)
- Push-уведомления

## 9. Открытые вопросы
- Финальный вординг текстов интерфейса
- Детальный список карт Таро и текстов толкований для MVP
- Детальная логика нумерологических расчётов (какие именно числа входят в полный набор)

## 10. Решённые технические параметры
- Платформа разработки: **только iOS**
- Нумерология: полный набор расчётов на старте — число судьбы, число души, число характера и т.д.
- Таро: полная колода **78 карт** (22 старших аркана + 56 младших) на старте
