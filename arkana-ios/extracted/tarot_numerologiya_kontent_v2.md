## ЧАСТЬ 2. НУМЕРОЛОГИЯ — формулы расчётов

Базовый принцип: цифры даты/имени складываются до однозначного числа, кроме «мастер-чисел» 11, 22, 33 — их не сокращают.

### Число судьбы (число жизненного пути)
Складываются все цифры полной даты рождения (день + месяц + год) до однозначного числа (с исключением для 11/22/33).
Пример: 14.03.1994 → 1+4+0+3+1+9+9+4 = 31 → 3+1 = 4.
Смысл: главный вектор жизни, задача, с которой человек пришёл.

### Число души (число внутреннего побуждения)
Складываются числовые значения гласных букв полного имени (по таблице соответствия букв кириллицы числам 1–9).
Смысл: то, чего человек хочет по-настоящему, его внутренние мотивы.

### Число характера (число личности)
Складываются числовые значения согласных букв полного имени.
Смысл: как человека воспринимают окружающие, внешний образ.

### Таблица букв кириллицы (числа 1–9, метод пифагорейской адаптации)
```
1: А И С Ъ
2: Б Й Т Ы
3: В К У Ь
4: Г Л Ф Э
5: Д М Х Ю
6: Е Н Ц Я
7: Ё О Ч
8: Ж П Ш
9: З Р Щ
```
*(таблицу нужно сверить/утвердить с приглашённым нумерологом-консультантом перед разработкой — распространены разные варианты адаптации)*

### Совместимость
Базовый MVP-метод: считаются числа судьбы обоих людей, затем оценивается их сочетание по заранее составленной таблице пар (например, 4+4 — стабильность и предсказуемость, 4+7 — разница темпов, нужен компромисс, и т.д.). Полную таблицу совместимости 9×9 нужно прописать отдельно.

### Прогноз дня
Складываются цифры числа судьбы человека с цифрами текущей даты, результат сводится до однозначного числа — под него подбирается готовый текст-толкование дня из банка формулировок (9 вариантов на каждое число 1–9, плюс мастер-числа).
