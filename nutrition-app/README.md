# Питание на 30 дней

Веб-приложение для трекинга плана питания на 30 дней (снижение веса на 5 кг). Полностью на русском, работает офлайн после первой загрузки, без бэкенда.

## Как открыть локально

```
cd nutrition-app
python3 -m http.server 8000
```

Затем открыть http://localhost:8000 в браузере.

(Можно открыть `index.html` двойным кликом, но некоторые браузеры блокируют локальные запросы — через `http.server` надёжнее.)

## Как изменить профиль (вес, возраст, цель)

Отредактировать `js/data.js`, объект `PROFILE` в начале файла. Расчёт калорий и БЖУ пересчитается автоматически.

## Как изменить план питания

Блюда и альтернативы для замены — в `js/data.js`, объект `MEAL_PLAN`. План — 10-дневный цикл, повторяется 3 раза на 30 дней.

## Хранение прогресса

Отметки о выполнении хранятся в localStorage браузера устройства, на котором открыто приложение. Между разными устройствами не синхронизируются.

## Деплой

При пуше в ветку `main` (в путях `nutrition-app/**`) автоматически публикуется на GitHub Pages через workflow `.github/workflows/deploy-nutrition-app.yml`. Нужно один раз включить в настройках репозитория: Settings → Pages → Source = "GitHub Actions".
