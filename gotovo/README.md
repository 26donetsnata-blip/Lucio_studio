# «Готово» — превью

Собранная статика приложения «что приготовить по фото холодильника».
Открывается по адресу https://26donetsnata-blip.github.io/Lucio_studio/gotovo/

**Это не исходники.** Исходный код живёт отдельно, в `~/Готово` (Next.js).
Здесь лежит только результат сборки — чтобы GitHub Pages было что раздавать.

**Превью временное.** Сейчас приложение целиком работает в браузере: профиль
хранится на устройстве, к серверу обращений нет. Как только появится
распознавание фото и генерация рецептов, понадобится сервер (там живёт ключ
Anthropic и проверка лимитов) — GitHub Pages такого не умеет, и превью
переедет на полноценный хостинг.

Что можно посмотреть: анкету профиля, главный экран, правку профиля.
