# «Готово» — превью

Собранная статика приложения «что приготовить по фото холодильника».
Открывается по адресу https://26donetsnata-blip.github.io/Lucio_studio/gotovo/

**Это не исходники.** Исходный код живёт отдельно, в `~/Готово` (Next.js).
Здесь лежит только результат сборки — чтобы GitHub Pages было что раздавать.

**Превью временное.** Сейчас приложение целиком работает в браузере, к серверу
обращений нет: распознавание продуктов и подбор рецептов пока сделаны
заглушками с фиксированными ответами — ключа Anthropic ещё нет. Как только
появятся настоящие вызовы модели, понадобится сервер (там живёт ключ и
проверка лимитов) — GitHub Pages такого не умеет, и превью переедет на
полноценный хостинг.

Что можно посмотреть целиком: анкету, главный экран «Что приготовим?»,
фото холодильника, подтверждение продуктов, ручной выбор продуктов, меню
и карточку рецепта.
